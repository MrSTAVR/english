# Прогон критиков

Аргументы: `$ARGUMENTS` (может быть пусто).

## 1. Определи объём
- Если в аргументах указана область (файлы, уроки, страницы, диапазон коммитов) — бери её.
- Иначе — изменения ветки относительно `main` плюс незакоммиченное: `git diff main...HEAD --stat`, `git status --short`. Если ветка — `main` и рабочая копия чистая, возьми последние коммиты с прошлого merge (`git log --oneline -15`) и уточни у владельца, если неясно.
- Git только читаем: не коммитим, не переключаем ветки.

## 2. Выбери критиков
Если в аргументах названы критики — только они. Иначе по затронутым файлам:
| Изменения | Критик |
|---|---|
| `data/*` (уроки, истории, диалоги, праздники), `review.py`, `grading.py` | `methodist` |
| страницы ученицы: `templates/`, `static/*.js|css`, `routes/student.py` и др. | `kid-ux` |
| `templates/`, `static/*.css`, SVG-рисунки, `*_art.py` | `design-critic` |
| монетки/кирпичики/награды: `garden.py`, `castle.py`, `wardrobe.py`, `achievements.py`, `weekly.py`, `friends.py`, `goals.py`, `stickers.py` | `game-balance` |
| любой Python/JS | `code-critic` |
Логопедическая часть (`speech*`, `templates/speech/`) — только `design-critic` (бирюзовая тема) и `code-critic`; `methodist`, `kid-ux`, `game-balance` её не касаются.

## 3. Запусти параллельно
Всех выбранных критиков — одним сообщением, несколько вызовов Agent (`subagent_type` = имя критика). В промпте каждому: объём (список файлов/коммитов, что за фича и зачем — 2–3 предложения контекста), просьба вернуть отчёт в его формате. Критики ничего не правят.

## 4. Сводный отчёт владельцу (по-русски, коротко)
```
## Итоги критики
Кто смотрел: ...  Общее впечатление: 2–3 предложения.

### Исправить обязательно
1. [критик] `файл:строка` — суть → предложение
### Стоит сделать
...
### Можно потом / в бэклог
...
### Расхождения мнений
(если критики противоречат друг другу — кратко, с твоей рекомендацией)
```
- Убери дубли между критиками, объедини похожие пункты.
- Проверь сомнительные находки по коду, прежде чем включать в «обязательно»; явно ложные — отбрось.
- **Ничего не исправляй сам.** В конце спроси владельца, какие пункты брать в работу (можно номерами), а отложенное предложи записать в бэклог `CLAUDE.md`.
