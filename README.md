# 🐣 English Fun — английский для дочки (10 лет, с нуля)

Веб-приложение на **Python (Flask + SQLite)** для изучения английского языка.
Два режима: **ученица** и **родитель**.

## Возможности

### 👧 Режим ученицы
- **8 уроков по 15–20 минут**: первые слова, цифры, животные, цвета, семья, еда, местоимения + глагол *to be*, части тела.
- Каждый урок из трёх шагов: **карточки слов → тренировки → итоговый тест**.
- Следующий урок открывается только после сдачи теста предыдущего (минимум 70%).
- **Трекер успеваемости**: уроки пройдены, средний балл, выученные слова, время занятий.
- **8 ачивок** для мотивации: 🚀 Первый шаг, ⭐ Три урока, 💯 Идеальный тест, 🔥 Огонь-машина, 🏆 Чемпион и др.

### 👨‍👩‍👧 Кабинет родителя (пароль по умолчанию: `1234`)
- Сколько **времени потрачено** на каждый урок и всего (старт/финиш каждой попытки).
- **Все ошибки** с таблицей: вопрос → ответ ребёнка → правильный ответ → подсказка.
- Прогресс по каждому уроку: статус, количество попыток, лучший результат.
- История всех занятий и полученные достижения.

## Запуск

```bash
pip install -r requirements.txt   # установит Flask
python3 app.py                    # или ./run.sh
```

Откройте в браузере: **http://localhost:5000**

## Настройка под себя
- **Новые уроки / свои слова**: редактируйте `data/lessons.py` — формат описан в комментарии сверху
  (типы заданий: `choice` — выбор ответа, `type_in` — вписать слово, `order` — собрать предложение,
  `match` — установить правильные пары drag&drop, `sort` — разделить слова по категориям drag&drop;
  поле `accept` добавляет альтернативные правильные ответы).
- **Пароль родителя**: константа `PARENT_PASSWORD` в `app.py`.
- **Проходной балл теста**: константа `PASS_MARK` в `app.py`.
- Все данные хранятся в файле `english_app.db` (SQLite) — просто удалите его, чтобы начать с чистого листа.

## Проверка работоспособности
```bash
python3 smoke_test.py
```
Автоматический тест проходит весь путь: вход → уроки → проваленный и идеальный тесты → ачивки → кабинет родителя → API ошибок.

## Git-воркфлоу (принятый алгоритм)

Все изменения попадают в `main` **только через pull request**:

1. Создать feature-ветку от актуального `main`: `git checkout -b <имя-ветки>`
2. Внести изменения и закоммитить: `git add -A && git commit -m "описание"`
3. Запушить ветку в origin и создать PR (`New pull request` на GitHub или `gh pr create`)
4. Проверить diff в PR и нажать **Merge pull request**
5. Удалить feature-ветку после слияния

Прямые push в `main` не выполняются.
