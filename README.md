# 🐣 English Fun — английский для ребёнка (с нуля)

Веб-приложение на **Python (Flask + SQLite)** для изучения английского языка.
Два режима: **ученик** (занимается) и **родитель** (создаёт аккаунты и следит за прогрессом).

## Возможности

### 👧 Ученик
- **Теория:** карточка «уроков пройдено» открывает правила из всех пройденных уроков (поиск, «раскрыть/свернуть все», кнопка «Повторить урок»).
- **Словарь:** карточка «слов выучено» открывает все слова из пройденных уроков: озвучка 🔊, «прослушать все», поиск и режим «скрыть перевод» для самопроверки.
- **32 основных урока** по 15–20 минут: фонетика и правила чтения (1–8), первые слова и грамматика (9–16),
  расширение кругозора (17–32): животные, *can*, еда, *Present Simple / Continuous*, одежда, дом, погода, хобби и итоговый рассказ о себе.
- **Дополнительные уроки** (сейчас — подготовка к диктанту): открыты всегда и не влияют на основной курс.
- Урок = **теория → карточки слов → тренировка → итоговый тест**. Следующий основной урок открывается,
  когда предыдущий сдан минимум на 70 % (`PASS_MARK` в `config.py`).
- 5 типов заданий: выбор ответа, ввод слова, составление предложения, соединение пар и раскладка по корзинам (drag & drop, на телефоне — касанием).
- **Озвучка** слов и фраз (кнопка 🔊) средствами браузера — нужен установленный английский голос.
- **Трекер успеваемости**: пройденные уроки, средний балл, выученные слова, время занятий.
- **34 награды** четырёх уровней (бронза / серебро / золото / легенда) в 8 категориях: уроки, тесты, ответы подряд, слова, время, упорство, сад, особые. Страница «Мои награды» со шкалами прогресса; вручает Чик-чик: подарок → медали по одной с эффектами по уровню (конфетти, салюты, вспышка для легенд).
- **Помощник Чик-чик:** живой SVG-цыплёнок (моргает, оглядывается, танцует, засыпает), много фраз и фактов; если быстро тыкать — надувается и взрывается перьями, потом возвращается (вихрь перьев / падение с неба / вылупление из яйца).
- **🌳 Сад**: каждый день серии (до 30 дней) приносит находку — травку, бабочку, зайчика, пруд, радугу, домик…
  Дерево растёт каждый день, а на 5/10/15/22/28-й день вырастают новые. Находки собираются в альбом.
  За сданный тест — +5 монет, за 100 % — ещё +5. На монеты покупаются украшения (15 штук: гирлянды, снег,
  самолётик, ночной фон…; до 5 одновременно; при снятии возвращается половина цены).
  Пропущенный день сбрасывает серию: сад «сдувается» до жёлудя, украшения пропадают, монеты остаются.

- **Праздники:** 🎃 Хэллоуин (15.10–3.11) и 🎄 Новый год (15.12–14.01): слова с озвучкой, викторина (+3 монетки в день), сезонные наряды Чик-чика, снегопад. В декабре — 🗓️ адвент-календарь: окошко со словом на каждый день (+1 монетка, если открыть в свой день).

### 🛠️ Администратор (родитель)
Вход — неприметная кнопка ⚙ в левом нижнем углу главной (страница `/admin`). Текущая версия сайта видна в подвале каждой страницы.

- **Зачёт пройденных уроков:** можно отметить уроки, пройденные в другой версии (всё до №N или выборочно), и снять зачёт. Монеты и серия не меняются.
- **Недельный отчёт:** дни занятий (🎯 цель выполнена, ✅ занимался, 🏖 каникулы), время, тесты и баллы, игры/истории/диалоги/письмо, частые ошибки и трудные слова; можно листать прошлые недели.
- **Цель дня** для каждого ученика: сколько уроков (0–3) и слов повторения (0–50); стандарт — 1 урок и 10 слов.
- Создание, удаление аккаунтов учеников и сброс паролей.
- Для каждого ученика: прогресс, средний балл, время занятий, ачивки, состояние сада (серию и монеты можно задать вручную).
- История всех попыток и **все ошибки** (вопрос → ответ ребёнка → правильный ответ → подсказка).

## Запуск

```bash
pip install -r requirements.txt
python app.py            # Windows: run.bat, Linux/macOS: ./run.sh
```

Откройте **http://localhost:5000**. Другой порт: `python app.py 8080` или переменная `PORT`.

Сначала войдите как родитель, создайте аккаунт ученика, затем ребёнок входит со своим логином и паролем.

### Настройки (переменные окружения)

| Переменная | Назначение | По умолчанию |
|---|---|---|
| `ENGLISH_ENV` | `production` включает строгие проверки для сервера | разработка |
| `ENGLISH_PARENT_PASSWORD` | пароль кабинета родителя (в production: от 8 символов, не `1234`) | `1234` — **смените!** |
| `ENGLISH_SECRET_KEY` | ключ подписи сессий (иначе файл `.secret_key`) | создаётся сам |
| `ENGLISH_APP_DB` | путь к файлу базы данных | `english_app.db` рядом с `app.py` |
| `ENGLISH_COOKIE_SECURE` | cookie только по HTTPS | включено в production |
| `ENGLISH_BEHIND_PROXY` | `1` — доверять заголовкам Caddy/nginx (реальный IP, https) | выключено |
| `ENGLISH_SESSION_DAYS` | сколько дней ребёнок остаётся «залогинен» | `30` |
| `ENGLISH_PARENT_SESSION_HOURS` | срок входа родителя | `12` |
| `ENGLISH_HOST` / `PORT` | адрес и порт `serve.py` | `127.0.0.1` / `8000` |
| `ENGLISH_BIND` | адрес gunicorn | `127.0.0.1:8000` |
| `ENGLISH_BACKUP_DIR` / `ENGLISH_BACKUP_KEEP` | папка и число копий для `backup_db.py` | `backups` / `14` |

Все переменные собраны в `.env.example`.

PowerShell: `$env:ENGLISH_PARENT_PASSWORD = "мой-пароль"; python app.py`
Linux/macOS: `ENGLISH_PARENT_PASSWORD=мой-пароль python3 app.py`

## Документация и агенты

- **Правила** — `AGENTS.md`. Один файл на весь проект: как запускать, что где лежит, какие ловушки. `CLAUDE.md` в корне — короткий указатель на него (часть инструментов ищет инструкции именно по этому имени).
- **Бэклог** — `BACKLOG.md`: отложенные задачи по приложению и по кабинету логопеда, отдельным разделом — уже сделанное. Новые идеи и решения владельца записываем туда, а не в переписку.
- **Критики** — `agents/`: независимые проверки после крупного блока изменений (методика, взгляд ребёнка, дизайн, экономика, код, QA). Брифы — обычный markdown, их отдают субагенту любого ассистента; порядок прогона и формат сводки — `agents/README.md`. Критики ничего не правят: отчёт → решение владельца.
- **Отчёты и аналитика** — вне репозитория, в `E:\Claude\EnglishFun-analytics\`: обзоры курса, концепции, прогоны критиков.

## Свои уроки

Редактируйте `data/lessons.py` (основной курс) или `data/extra_lessons.py` (дополнительные, флаг `"is_extra": True`).
Формат урока описан в комментарии в начале `lessons.py`: `theory`, `material` (карточки), `exercises` (тренировка), `test`.
Типы заданий: `choice`, `type_in` (поле `accept` — альтернативные ответы), `order`, `match`, `sort`.
После правок запустите `pytest` — тест `test_lessons_data.py` проверит целостность данных.

## Тесты

```bash
pip install -r requirements-dev.txt
pytest
```

Тесты работают на временной базе данных и не трогают `english_app.db`.
Они проходят весь путь: вход → уроки → тесты → ачивки → кабинет родителя → CSRF.

## Запуск на сервере

```bash
export ENGLISH_ENV=production ENGLISH_BEHIND_PROXY=1
export ENGLISH_PARENT_PASSWORD='длинный-пароль'
gunicorn -c gunicorn.conf.py wsgi:app      # Linux; на Windows: python serve.py
```

В режиме `production` приложение **не запустится**, если пароль родителя простой или не задан.
Перед ним ставится прокси с HTTPS (Caddy/nginx). Проверка работоспособности: `/healthz`.
Резервная копия: `python backup_db.py` (безопасна при работающем приложении).

## Мобильное приложение (PWA)

Сайт устанавливается на телефон как приложение: своя иконка, запуск без адресной строки, офлайн-страница при обрыве сети.
Нужен HTTPS (на сервере он есть).
- **Android (Chrome):** на сайте появится кнопка «📲 Установить» (или меню ⋮ → «Установить приложение»).
- **iPhone (Safari):** «Поделиться» ⬆️ → «На экран Домой».

Шрифт Nunito хранится в проекте: один раз выполните `python tools/fetch_fonts.py`.
Иконки рисует `python tools/make_icons.py` (нужен `pip install pillow`).
Service worker (`/sw.js`) кэширует только статику; страницы и формы всегда идут через сервер.

Установка, обновление, копии и восстановление на VPS: папка `deploy/` и `deploy/OPERATIONS.md`.

## Безопасность

- Пароли учеников хранятся как хеш PBKDF2; POST-формы защищены CSRF-токеном.
- Вход ограничен: после серии неудач аккаунт, кабинет родителя и IP блокируются на 10 минут.
- Cookie: HttpOnly, SameSite=Lax, Secure в production; вход родителя истекает через 12 часов.
- Заголовки безопасности, `noindex`, лимит размера запроса, HSTS по HTTPS.
- Файл `.secret_key`, `.env` и `backups/` не публикуйте (они в `.gitignore`).
- Без `ENGLISH_ENV=production` сервер слушает все интерфейсы (`python app.py`) — это режим домашней сети.


## 🎤 Произношение и новые задания

- В каждый тест добавлены 2 вопроса «на слух» (послушай → выбери перевод, диктант), а в тренировке урока — блок «Ещё потренируемся» (слушай, диктант, собери слово из букв, перевод).
- Страница **«Говорим»** (`/student/speak`) и блок «Скажи вслух» в уроке: ребёнок нажимает 🎤, говорит слово, браузер распознаёт речь, мы сравниваем с нужным словом и ставим 0–3 ⭐. Оценки хранятся в таблице `speaking`, родитель видит число слов в кабинете, есть ачивки за произношение.
- Это проверка «тебя поняли?», а не фонетический разбор.
- Нужен HTTPS (или localhost) и разрешение на микрофон. Работает в Chrome, Edge, Safari; в Firefox микрофонных заданий нет (остальное работает).
- Приватность: наш сервер получает только оценку. Chrome/Edge сами отправляют запись на распознавание в облако Google/Microsoft.
- Отключить: `ENGLISH_SPEAKING=0` в `.env`.
