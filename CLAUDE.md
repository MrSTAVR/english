# English Fun — заметки для Claude Code

Веб-приложение для изучения английского ребёнком (10 лет, ученица «Маша»): Flask + SQLite, без фронтенд-сборки (чистый JS/CSS). Рядом ходит родитель (владелец проекта). Подробности о возможностях — в `README.md`, эксплуатация — в `deploy/OPERATIONS.md`.

## Как общаться
- Владелец говорит по-русски: отвечай по-русски, коротко и по делу. Тексты интерфейса — тоже по-русски, дружелюбно, для ребёнка.
- Окружение владельца: Windows + PyCharm, репозиторий `MrSTAVR/english` (ветка `main`).
- Валюта в учебных текстах — **рубли** (не фунты/доллары).

## Команды
- Запуск: `pip install -r requirements-dev.txt`, затем `python app.py` (http://localhost:5000). Пароль родителя по умолчанию `1234` (только для разработки).
- Тесты: `pytest` (конфиг в `pytest.ini`). **Перед каждым коммитом тесты должны быть зелёными.** Тесты идут с отключённым CSRF.
- Деплой на сервер (Debian, Caddy + systemd): автоматически из `main` раз в 5 минут; вручную — `bash /opt/english/app/deploy/update.sh`. Новые таблицы БД создаются сами при старте.
- Новые файлы не забывать добавлять в git (в PyCharm — «Add to VCS»).

- Контент: `data/lessons.py`, `new_lessons.py`, `more_lessons.py`, `later_lessons.py` (52–60: was/were, -ed/did, сравнения, «как часто», путешествия, неправильные глаголы, will, going to, в гостях), `topic_lessons.py` (id 61+: «Проверь себя» в конце островов — 61, 62, 64, 66; новые темы — 63 «Чьё это? Порядок прохождения задаёт `data/course.py`: острова `ISLANDS` (название + id уроков, до 9 на острове) → `ORDER`; он не равен id урока. **Ловушка:** урок открыт, если сдан любой урок после него, — сданные детьми уроки нельзя переносить далеко вперёд (тест `test_children_progress_stays_in_first_island`); в тестах «первый урок курса» — `N(1)`, а не id 1. Диалоги — `data/dialogs.py`, истории — `data/stories.py`, праздники — `data/halloween.py`, `newyear.py` (+ `ADVENT` — 31 окошко), `march8.py`, `easter.py`, `birthday.py` (слова, викторина, тексты страницы), эмодзи — `data/emoji.py` (для слов без подходящего эмодзи — свои рисунки `static/pics/<слово>.svg`, в данных «@слово», список `DRAWN`; выводятся фильтром `|pic` и `window.picHtml` из `base.html` — новые места показа картинок слов делаем через них).

- Фронтенд: `templates/` (Jinja), `static/` (`style.css`, `theme.css` — тема перекрывает style.css, `games.js`, `stories.js`, `writing.js`, `chick.js` — рисунок цыплёнка и наряды, `house.js`, `mascot.js`, `tts.js`, `sw.js`, `pwa.js`…).

## Важные правила и ловушки

English Fun: кремовый фон `#FFF7E8`, синий акцент `#2563C9`, жёлтый `#FFC83D` (Чик-чик и главная кнопка), белые карточки с рамкой 2px `#F0E3C8` и тенью снизу, Nunito. Логопед и семья (`body.area-speech`): бирюза `#1F6F66`, Manrope, тонкие рамки без теней, без Чик-чика. Цвета — только через переменные (`--primary`, `--tint`, `--line`…), их задаёт `static/design.css` (подключён последним, там же тёмные темы обеих частей). Шрифты локальные (`tools/fetch_fonts.py`). У Чик-чика один клюв. **Значки:** цветных эмодзи в интерфейсе нет — только картинки к словам в уроках/играх, рисунки сада/домика/наклеек и босс; иконки — контурные из спрайта в `base.html` (`<svg class="ico"><use href="#o-sound"/></svg>`, `#o-*`, `#i-*` кроме цветных `#i-coin`/`#i-chick`); тексты из данных (названия уроков, баннеры, сообщения) выводим через фильтр `|noemoji`, реплики Чик-чика чистит `mascot.js`. Цвета — только из палитры макета (никаких градиентов в полосках и карточках). Меню: ученица — `.tabbar` в шапке, на телефоне внизу (`body.has-tabbar`, 6-я ячейка — Чик-чик); логопед — `body.sp-logoped`, ≥1024px слева, на телефоне внизу.
- **Урок** (`templates/lesson.html`, `static/lesson.css` + `static/lesson.js`, макет — артборды «Урок, шаг 1–4» телефон/компьютер): **тренировки в уроке нет** (владелец 29.10.2026: скучно, силы — на историю; данные `exercises`/`practice` в уроках остались, но не показываются; игры по словам урока — кнопка «Сыграй со словами урока» на странице результата). Шаги: урок со сценой — «Теория → История», без сцены — «Теория → Слова → Тест» (список шагов — `ls_steps` в шаблоне, `lesson.js` берёт их из шапки; шаг старого сохранения, которого больше нет, ведёт к тесту/истории). Шапка с шагами (на телефоне — крестик и полоска, верхнее меню скрыто, `body.lesson-focus`), теория карточками (английские фразы жирным озвучиваются по нажатию), «Новые слова» — одна большая карточка (перевод по нажатию, точки, «Дальше»), список всех слов справа или в шторке «Все слова»; данные — JSON `#wd-data` из `lesson.material`. Незаконченный урок сохраняется (`lesson_progress`, `POST /api/lesson/<id>/progress`: шаг и место на странице, слово, ответы теста, «Соедини пары», «Разложи по корзинам», собранные предложения, место в сцене — `window.LessonScene`, секунды; компоненты сообщают об изменениях событием `lesson:changed`) и восстанавливается при возврате (плашка «Продолжаем с того же места» + «Начать заново»); после сдачи теста строка стирается. Задания «напиши по-английски» (тест, сцена, повторение): под полем буквы-плитки и «Подсказка» (маска «f _ _ _») — `static/tiles.js`, плитки из фильтра `|tiles` (`template_filters.letter_tiles`, перемешаны одинаково при каждом открытии, ответ целиком в страницу не попадает); в тесте и сцене уроков курса до `TILES_UPTO` плитки открыты сразу, дальше — по кнопке; ответ с подсказкой/плитками (`q<i>_help`, ставится при нажатии плитки или кнопки) засчитывается, но слово уходит в повторение. Ответы сравниваются после `grading.norm_answer` (регистр, знаки препинания и внутри фразы, сокращения = полные формы: he's = he is, don't = do not — `CONTRACTIONS`; лишний артикль в начале ответа без артикля не ошибка — `drop_article`, «an egg» = «egg»; в браузере то же — `LetterTiles.norm`). Мелкие опечатки (`grading.near_answer`) засчитываются только в английских ответах: опечатка максимум в одном слове от 5 букв, первая буква та же, введено не другое слово курса (`grading.dictionary()` — все тексты уроков/историй/диалогов + `FUNCTION_WORDS`) и не другая форма (-s/-es/-ed/-ing, удвоенная буква); в результатах — «Засчитано! Только пишется так…», слово — в повторение; в браузере то же (`LetterTiles.near`, словарь урока — `#near-dict` из `grading.near_dict`). Варианты «выбери» в уроке перемешиваются стабильно (`|shuffle_options`, value — исходный индекс). Тест урока собирается в `practice.augment`: свои вопросы (лишние «напиши по-английски» сверх `MAX_WRITE`=2 на слова урока превращаются в «выбери» — `limit_writing`) + вопрос на слух + 1 повторение из прошлых уроков без фонетики (`review_extras`, `PHONICS_IDS`); итого не больше 10. Результат теста: при провале — «Не хватило N ответов» / «Этот урок пока трудный», главная кнопка «Исправь ошибки (N)» (`/lesson/<id>?step=test&fix=<attempt>`: верные ответы прошлой несданной попытки засчитаны — `routes/student.fix_correct`, вопросы скрыты `.fix-done`, на сдачу идёт `fix_from`; «Идеально» и бонус за 100% — только с первого раза), «Пройти весь тест заново» (`?step=test`), в разборе — только ошибки, у «выбери» — текст выбранного варианта. Повторная отправка теста: в течение минуты — на главную с сообщением, позже (страница из офлайн-кэша) — новая попытка; попытка другого урока — 400.
- **История «Поездка к Тому» вместо теста** (`data/story.py` — сюжет по островам и сцены `SCENES[id урока]`, `scenes.py` — данные для чата, `templates/_scene.html`, `static/scene.js`): у урока со сценой шаги «Теория → История» (шага «Слова» нет: слова урока из `material` при первом появлении в реплике героя — карточки под ней с картинкой, перевод по нажатию, в тексте слово подчёркнуто). История — чат: реплики героев (`say`, только английский, озвучиваются по очереди после кнопки «Начать историю»; кнопка «перевод», поэтому в реплике над вопросом не называем проверяемое слово; `{name}` — имя ученицы, в английском латиницей — `scenes.name_en`), слова рассказчика (`note`), ходы ученицы (`ask(q, ok=say(...), no=say(...) | {номер варианта: say(...)})` — choice (можно `pics=True` — варианты картинками) / type_in с `accept` / order, можно `audio`; `ok`/`no` — реакция героя на ответ, неверный ответ виден в чате зачёркнутым), выбор без правильного ответа (`pick(ключ, вопрос, [(en, ru, v, v_ru)…])` — дальше `{ключ}` в репликах; в тест не входит), «скажи вслух» (`speak(en, ru)` — по желанию, без оценки), в конце крючок `outro`. Правила хода для новых сцен (методист 29.10.2026): ход — реплика в разговоре, а не «выбери перевод»; без «напиши перевод по-русски»; письмо не больше 2 раз и по сюжету (записка, код, табличка); каждое ключевое слово — 3 раза (услышала → выбрала → применила); реакция `no` — максимум на 1 вариант; образец — сцена урока 10. Вопросы сцены и есть `lesson["test"]` (`practice.augment` без `limit_writing`/«на слух»; «Повторение» — после сцены), поэтому сдача, «Исправь ошибки» (засчитанные ходы показываются ответом), монетки и повторение — как у теста. Ответ проверяется сразу (вторая попытка, после двух ошибок — верный ответ и сюжет идёт дальше); на сервер уходят первый ответ (`q<i>` / `q<i>_order`, балл) и второй (`q<i>_2` / `q<i>_order_2` — полбалла, слово всё равно в повторение); порог сцены — `config.PASS_MARK_SCENE`=60% (`curriculum.pass_mark`); место в сцене — `window.LessonScene` в `lesson_progress`. Проверка данных — `curriculum.validate_scenes` (5–`SCENE_MAX` ходов, известные герои, реакции, `{ключ}` только после `pick`), тесты — `tests/test_scenes.py`. Сделан остров 1 («Первые шаги»); новые сцены сначала проверяет `methodist`.
- **Телефон:** вёрстка должна помещаться в 360px без горизонтальной прокрутки (узкие правки — в конце `theme.css`).
- **Кэш статики:** при правке JS/CSS поднимай `?v=N` у подключения в `templates/base.html` (или в шаблоне страницы), иначе у ребёнка останется старый файл. `sw.js` версионируется сам.
- **CSRF:** в формах — скрытое поле `csrf_token()`; в `fetch` — заголовок `X-CSRF-Token` из `<meta name="csrf-token">`. Токен вычисляется из зерна сессии (`csrf.new_seed()` — сразу после `session.clear()` при входе), не хранится: иначе параллельные запросы перетирали его в cookie и сохранения падали с «Форма устарела».
- В шаблонах HTML из данных урока выводится через `|safe` (теория), остальное экранируется.
- Серия дней (`garden.compute_streak_from_history`) считается по дням реальных занятий (`garden.study_days`: пройденный тест урока, `activity` — игра/история/диалог/урок, `daily_goal` со словами), открыть урок — не занятие. Каникулы родителя (таблица `vacations`) серию не прерывают; один пропущенный день тоже не рвёт («запасной день», не чаще раза в `FREEZE_EVERY`=7 дней). При разрыве сад «засыпает» (серый, дерево — жёлудь), украшения остаются. Монетки за тест — `garden.award_coins`: первая сдача `COIN_PASS` (+`COIN_PERFECT` за первые 100% не после «Исправь ошибки»), пересдача — `COIN_RETRY` только за новый лучший результат и раз в день на урок, провал от `EFFORT_MIN`% — `COIN_EFFORT` «за старание» раз в день. Крыша замка — за `castle.ROOF_DAYS`=10 дней занятий всего; награды `days_10/20/40` (метрика `study_days`). Любые правки в `garden.py` проверяй тестами `tests/test_vacation.py`, `tests/test_garden.py`, `tests/test_coins.py`.
- Офлайн: `static/sw.js` кэширует посещённые страницы уроков/игр (`OFFLINE_OK`), при выходе из аккаунта кэш страниц стирается. Новая страница ученика, которая должна работать офлайн, добавляется в regex `OFFLINE_OK`.
- Праздники: `seasons.SEASONS` (даты `start`/`end` могут переходить через Новый год; у Пасхи `window` — православная Пасха считается `orthodox_easter`), свои даты родителя можно сделать «каждый год» (`season_<key>_yearly`). День рождения — личный праздник: `students.birthday` (поле в кабинете администратора), неделя после даты, страница `/student/birthday` (общий `season.html`), подарок `BIRTHDAY_GIFT` монет раз в год (`birthday_gifts`). `seasons.active_season()` учитывает настройку родителя (авто / включён / выключен + свои даты, таблица `app_settings`). Новый праздник = запись в `SEASONS` + `data/<key>.py` с теми же полями, что у `halloween.py`; страница `/student/<key>` и `/api/<key>` общие (`templates/season.html`, `static/season.js`). Адвент-календарь (`/student/advent`, таблица `advent`) — весь декабрь, выключается вместе с Новым годом; монетка только за окошко, открытое в свой день. Снегопад — `snow` в `app.py` (context processor). Сезонные наряды покупаются только в сезон; купленное остаётся навсегда.
- **«Друзья» (соревнования):** `friends.py` + `routes/friends.py`, страница `/student/friends` (плитка в «Мой мир», бейдж — `news_count`, баннер вызова на главной). Участвуют ученики с `students.competitions=1` (переключатель «Соревнования» в карточке ученика у администратора); другим видны только имя и аватарка. Рекорды — `game_records` (что считаем и в какую сторону — `friends.RECORDS`, `/api/game` принимает `score`); дуэли — `duels` (одинаковые слова из общих выученных, одна попытка у каждого, вызвавший играет первым, ждём `DUEL_DAYS`, монетки за первые `DUEL_COINS_PER_DAY` дуэли в день; игра открывается `?duel=<id>`); лента — `feed` (`friends.post`: первый сданный урок, новые награды из `update_achievements`, рекорд среди друзей, итог дуэли) и готовые реакции `feed_reactions` (без свободного текста); «в гостях» — `/student/friends/<id>/garden|house` и «нравится» (`likes`). Тексты ленты — без имён в косвенных падежах и без глаголов с родом («Урок пройден: …»).
- **Замок Чик-чика** (вместо домика; `/student/house` → редирект): `castle.py` + `routes/castle.py`, рисунки — `castle_art.py` (SVG комнат, зверят-соседей, кирпичика, ворот), шаблоны `castle.html`, `castle_room.html`, макрос `_castle.html` (импорт `with context`), `static/castle.css|js`. Таблицы `castle` (переезд: при первом входе `ensure` возвращает монетки за вещи домика и стирает их), `castle_rooms` (уровень 1–3), `castle_bricks` (журнал кирпичиков, UNIQUE(reason, ref) — начисление один раз). Кирпичики только за учёбу: первый сданный урок (`on_lesson_passed` в `submit_test`), урок замка (уроки 20001–20006, `data/castle_lessons.py`), цель дня (`goals.add`). 1. Небольшой шаг → тесты (добавляем новые в `tests/`) → проверка в браузере для UI (Playwright + Chromium, если нужно).
2. Публикация делается целиком самостоятельно (как «Commit and Push» в PyCharm): тесты зелёные → коммит → push в рабочую ветку → PR через REST API (`gh api repos/MrSTAVR/english/pulls -X POST …`; GraphQL в облачных сессиях закрыт, `gh pr …` не работает) → дождаться зелёного CI (GitHub Actions `tests`: Python 3.11 как на сервере, `pytest`; статус — `gh api repos/MrSTAVR/english/commits/<sha>/check-runs`) → merge (`gh api repos/MrSTAVR/english/pulls/<N>/merge -X PUT`). Если тесты или CI красные или merge не прошёл — не сливать, сообщить владельцу.
3. Выкатка: сервер сам подтягивает `main` раз в 5 минут (`deploy/autoupdate.sh` + таймер `english-autoupdate.timer`, включается `deploy/setup-autoupdate.sh`), при поломке откатывается; кабинет администратора управляет им через «записки» в `/opt/english/data/control` (`updates.py`, блок «Обновления сайта»: журнал, «Обновить сейчас», вкл/выкл). Новые таблицы БД — только аддитивно (`CREATE TABLE IF NOT EXISTS`/`ALTER TABLE ADD`), чтобы откат кода не ломал базу.
4. Критики проекта — сабагенты в `.claude/agents/` (`methodist` — английский и методика, `kid-ux` — взгляд ребёнка и телефон, `design-critic` — макет, `game-balance` — монетки и награды, `code-critic` — правила этого файла); общий прогон — `/critique` после крупного блока изменений.
